# Контент Telegram Service Bot в Directus

Бот использует общее пространство Directus с ключом:

```text
telegram-service-bot
```

Для него нужно создать отдельную запись в **Content Bots**. Записи другого бота он не читает.

## Как создать экран

1. Откройте **Responses**.
2. В поле **Bot** выберите Telegram Service Bot.
3. В поле **Name** укажите один из технических ключей из таблицы ниже.
4. Установите статус **Опубликован**.
5. Создайте связанные **Response Blocks**.
6. При необходимости создайте **Response Buttons**.

Для каждого ключа должна существовать не более чем одна опубликованная запись.

## Доступные ключи

| Name                   | Где используется             |
| ---------------------- | ---------------------------- |
| `screen.main`          | Приветствие и главное меню   |
| `screen.complexes`     | Выбор комплекса              |
| `form.massage_type`    | Выбор вида массажа           |
| `form.concern`         | Вопрос о задаче массажа      |
| `form.exercise_format` | Формат занятия ЛФК           |
| `form.exercise_goal`   | Цель занятия ЛФК             |
| `form.advice_request`  | Запрос на консультацию       |
| `form.name`            | Имя клиента                  |
| `form.phone`           | Телефон                      |
| `form.preferred_time`  | Удобное время                |
| `form.preferred_days`  | Удобные дни                  |
| `form.privacy`         | Согласие на обработку данных |
| `complex.1`            | Первый комплекс              |
| `complex.2`            | Второй комплекс              |

Если записи нет или Directus временно недоступен, интерфейсные экраны используют безопасный встроенный текст. Для комплексов вместо отсутствующего материала показывается сообщение «Материал пока не опубликован».

## Кнопки сценариев

Для кнопки-команды выберите `action = text`, а в `target` укажите точное значение:

| Действие          | Target                  |
| ----------------- | ----------------------- |
| Главное меню      | `menu`                  |
| Список комплексов | `complexes`             |
| Массаж            | `flow:massage`          |
| ЛФК               | `flow:exercise_therapy` |
| Помощь с выбором  | `flow:advice`           |
| Комплекс №1       | `complex:1`             |
| Комплекс №2       | `complex:2`             |
| Принять согласие  | `privacy:accept`        |
| Отказаться        | `privacy:decline`       |

Значение `target` техническое. Если изменить его произвольно, кнопка не выполнит действие.

Для обычной ссылки выберите `action = open_link` и вставьте полный адрес `https://...`.

## Комплекс в виде ссылки

В `complex.1` или `complex.2`:

1. Добавьте текстовый блок с коротким описанием.
2. Добавьте кнопку `open_link`.
3. Вставьте ссылку на страницу или опубликованный файл.

Если используется Яндекс Диск, обычная публичная ссылка подходит именно для кнопки «Открыть». Она не загружается в Telegram автоматически.

## Фото, видео или документ с Яндекс Диска

1. Загрузите оригинал на Яндекс Диск.
2. В **Media Assets** создайте материал и выберите Telegram Service Bot.
3. Выберите тип: `photo`, `video`, `audio` или `document`.
4. В **Yandex Path** укажите полный путь, например `/Telegram Bot/complex-1.mp4`.
5. Выберите статус **В очереди**.
6. Подождите, пока статус станет **Готов**.

Worker один раз передаст файл потоком в закрытую техническую Telegram-группу. После успешной загрузки поля `telegram_file_id`, `telegram_file_unique_id`, `mime_type` и `file_size` заполняются автоматически. Постоянная копия на сервере не создаётся.

Затем в нужном **Response Block**:

1. Выберите такой же тип блока.
2. В поле **Media** выберите подготовленный Media Asset.
3. Оставьте **Body** пустым.

При выдаче бот использует `telegram_file_id` и больше не обращается к Яндекс Диску.

Ограничения автоматической подготовки через облачный Telegram Bot API:

- фотография — до 10 МБ;
- видео, аудио или документ — до 50 МБ.

Файл большего размера получит статус **Ошибка** с понятным описанием. Оригинал на Яндекс Диске при этом не изменяется.

## Что редактору не нужно менять

- `CONTENT_BOT_KEY`;
- ID группы и канала;
- токен Telegram;
- структуру анкеты;
- значения callback-команд вне приведённой таблицы;
- сроки хранения персональных данных.
